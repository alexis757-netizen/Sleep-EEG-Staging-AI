# Sleep-EEG-Staging-AI


基于真实临床睡眠多导睡眠图（PSG）数据的自动睡眠分期系统（Automatic Sleep Staging）。项目涵盖从真实医疗级 EDF 数据解析、多模态标签对齐，到特征工程与深度学习建模的全流程。


\## 📌 项目进度与日志 (Daily Logs)


\### Day 01: 真实睡眠数据解析、波形可视化与基线模型 (Baseline)
\*\*数据加载与对齐\*\*：使用 `mne` 读取 PhysioNet Sleep-EDF 数据库。成功将 PSG 原始波形与专家人工标注的 `Hypnogram` 进行时间轴对齐。
 \*\*数据清洗与修复\*\*：处理了旧版医学标准中 `Sleep stage 4` 造成的标签重复映射冲突，统一归并为深睡期（N3）。
 \*\*临床可视化\*\*：提取 30 秒标准 Epoch，成功绘制出清醒期（W）、中睡期（N2，含 K复合波/纺锤波）与深睡期（N3，Delta 慢波）的经典波形对比图。
 \*\*频域特征提取\*\*：利用 Welch 法计算 0.5-30Hz 内的频段相对能量（Delta, Theta, Alpha, Beta）。
\*\*基线模型评估\*\*：使用 RandomForest 结合分层 K 折交叉验证（StratifiedKFold）训练多分类模型，并输出混淆矩阵。

\*\*工程发现：\*\*
1\. 真实睡眠数据极不平衡，N1（浅睡）与 REM（做梦）样本极其稀缺，且单通道脑电下极易混淆。
2\. 纯手工频段特征在区分深睡（N3）时表现优异（因为慢波极其明显），但在区分 N1 和 REM 时遭遇瓶颈，证明需要引入更强大的深度学习模型进行自动特征提取。


### Day 02: 基于 1D CNN 的自动睡眠分期基线与多分类挑战
- **模型架构**：抛弃了手工特征提取，直接构建 1D CNN（一维卷积神经网络），接收长度为 3000（30秒 * 100Hz）的原始脑电时序波形。
- **解决医疗类别不平衡**：针对睡眠数据中 N1（浅睡）和 REM（做梦）样本极度稀缺的问题，引入 `compute_class_weight` 计算类别权重，并应用于交叉熵损失函数（CrossEntropyLoss），强制模型关注少数类。
- **网络设计**：包含两层 Conv1d（提取波形特征） + BatchNorm（加速收敛） + MaxPool1d（降维） + Dropout（防过拟合） + 自适应池化（AdaptiveAvgPool1d）。

**实验结果与医学分析：**
- **总体表现**：模型整体准确率达到 **65%**，Loss 曲线从 1.7 稳定下降至 1.1，收敛良好。
- **深睡识别（N3）**：表现极佳，Recall（召回率）高达 **90%**。证明深度睡眠期巨大的 Delta 慢波特征极其明显，CNN 极易捕捉。
- **边界混淆（N1 与 W）**：N1（浅睡）有较大概率被错判为 W（清醒）。医学解释：N1 是清醒到睡眠的过渡期，两者在单通道脑电上的高频特征极度相似。
- **REM 期失效**：模型几乎无法识别 REM（做梦）期。工程反思：单通道脑电数据（仅有 Fpz-Cz）不足以支撑 REM 判读，必须引入眼电（EOG）和肌电（EMG）辅助。这为后续的“多通道数据融合”埋下伏笔。

### Day 03: 多通道数据融合（EEG + EOG + EMG）的尝试与深度反思
- **模型架构**：将输入通道从 1 扩展为 3，引入 `EEG Fpz-Cz`, `EOG horizontal`, `EMG submental` 联合输入 1D CNN。
- **实验结果（翻车）**：总体准确率从前一天的 65% 降至 **54%**。其中 N2（中睡）和 REM（做梦）的召回率直接归零。模型陷入“类别坍塌”，几乎把所有非清醒样本都预测成了深睡（N3）。
- **工程反思（核心）**：
  1. **多模态量级差异**：EEG、EOG、EMG 的绝对幅值差异极大。目前的“全局归一化”破坏了信号的物理特征，导致模型无法有效区分。
  2. **小样本下的维度灾难**：特征维度从 3000 个点瞬间涨到 9000 个点（3通道），而总样本仅 130 个。模型未能学到复杂的融合特征，反而依靠慢波特征“偷懒”全猜 N3。
  3. **类别极度不平衡**：测试集中 REM 仅 1 个样本，毫无统计意义。
- **改进方向**：后续需引入按通道独立标准化（Channel-wise Normalization）、多分支独立卷积网络，或大幅扩充样本量。

### Day 04: 10 人群体数据扩展与多通道独立标准化
- **数据扩充**：将受试者从 1 人扩展至 10 人（Subject 0-9），总样本量突破 2000+ 个 30 秒 Epoch。
- **核心技术（独立标准化）**：修正了多模态融合的致命错误。采用按通道独立标准化（Channel-wise Normalization, `axis=(0, 2)`），分别计算 EEG、EOG、EMG 的均值和方差，防止极大幅值的眼电/肌电吞没脑电信号。
- **实验结果**：整体准确率提升至 **60%** 左右。
  - **深层突破**：REM（做梦）和 N1（浅睡）的召回率成功破零！模型成功识别出 16 个 REM 和 22 个 N1。证明模型确实学会了利用多模态（眼动、肌张力）特征。
  - **边界混淆（致命痛点）**：N2（中睡）有大量样本被错判为 N3（深睡）。医学原因是 N2 期的 K复合波与 N3 期的 Delta 慢波在局部波形上极其相似，模型被巨大慢波严重带偏。
- **优化方向**：单纯看 30 秒孤立切片缺乏睡眠上下文逻辑。下一步需引入时序模型（如 LSTM/RNN）捕捉睡眠状态转移的连续性。

### Day 05: CRNN (1D CNN + LSTM) 引入时序上下文记忆
- **模型升级**：将 1D CNN 与双向 LSTM 结合，构建了 CRNN 架构。将孤立的 30 秒 Epoch 转化为序列（`seq_length=5`），让模型利用前 150 秒的上下文来预测当前的睡眠状态。
- **数据重构**：自定义 `SleepSequenceDataset`，重写数据加载逻辑，增加时间轴维度。
- **实验结果**：总体准确率维持在 **61%** 左右，Loss 收敛至 0.7。
- **深入分析**：虽然总体准确率未显著暴涨，但**结构发生了积极变化**。N2（中睡）的召回率从昨天的 35% 跃升至 **56%**，说明模型成功利用 LSTM 记住了“状态转换”。目前的核心瓶颈在于 N2 与 N3 的医学边界极其模糊，且 `seq_length=5` 的记忆窗口依然偏短。未来可尝试多模态晚期融合或增加序列长度。

### Day 06: 架构大比拼 (长记忆 vs 多分支融合) 与消融实验
- **实验目的**：为了突破 61% 的准确率瓶颈，设计了两套不同的优化方案进行对比。
  - **Plan A (长记忆序列)**：将 `seq_length` 扩展至 15（记住过去 7.5 分钟），测试 LSTM 对长上下文的捕捉能力。
  - **Plan B (多分支晚期融合)**：放弃“三通道混合卷积”，采用三个独立的 CNN 分别处理 EEG、EOG、EMG，最后再拼接特征，解决多模态频率差异过大导致的特征冲突问题。
- **实验结果**：**Plan B (多分支融合) 效果显著优于 Plan A**。证明在医疗多模态数据中，“先独立提取特征，后融合”是更优的架构。
- **失败尝试记录（缝合怪）**：后续尝试了将 Plan B 与长序列 LSTM（seq_length=10）强行结合的终极融合模型。但实验发现，参数量骤增导致模型严重过拟合，效果反而不如单一的 Plan B。这证明了在深度学习工程中，“模型越复杂不等于越好”，需要根据数据量和算力进行权衡。
- **工程反思**：多模态融合不应简单粗暴地将不同物理量混在一起卷积，独立分支的设计大幅降低了特征学习的认知负荷。后续将持续以 Plan B 作为最终的 Baseline 架构。

\# Sleep-EEG-Staging-AI



基于真实临床睡眠多导睡眠图（PSG）数据的自动睡眠分期系统（Automatic Sleep Staging）。项目涵盖从真实医疗级 EDF 数据解析、多模态标签对齐，到特征工程与深度学习建模的全流程。



\## 📌 项目进度与日志 (Daily Logs)



\### Day 01: 真实睡眠数据解析、波形可视化与基线模型 (Baseline)

\- \*\*数据加载与对齐\*\*：使用 `mne` 读取 PhysioNet Sleep-EDF 数据库。成功将 PSG 原始波形与专家人工标注的 `Hypnogram` 进行时间轴对齐。

\- \*\*数据清洗与修复\*\*：处理了旧版医学标准中 `Sleep stage 4` 造成的标签重复映射冲突，统一归并为深睡期（N3）。

\- \*\*临床可视化\*\*：提取 30 秒标准 Epoch，成功绘制出清醒期（W）、中睡期（N2，含 K复合波/纺锤波）与深睡期（N3，Delta 慢波）的经典波形对比图。

\- \*\*频域特征提取\*\*：利用 Welch 法计算 0.5-30Hz 内的频段相对能量（Delta, Theta, Alpha, Beta）。

\- \*\*基线模型评估\*\*：使用 RandomForest 结合分层 K 折交叉验证（StratifiedKFold）训练多分类模型，并输出混淆矩阵。



\*\*工程发现：\*\*

1\. 真实睡眠数据极不平衡，N1（浅睡）与 REM（做梦）样本极其稀缺，且单通道脑电下极易混淆。

2\. 纯手工频段特征在区分深睡（N3）时表现优异（因为慢波极其明显），但在区分 N1 和 REM 时遭遇瓶颈，证明需要引入更强大的深度学习模型进行自动特征提取。

### Day 02: 基于 1D CNN 的自动睡眠分期基线与多分类挑战
- **模型架构**：抛弃了手工特征提取，直接构建 1D CNN（一维卷积神经网络），接收长度为 3000（30秒 * 100Hz）的原始脑电时序波形。
- **解决医疗类别不平衡**：针对睡眠数据中 N1（浅睡）和 REM（做梦）样本极度稀缺的问题，引入 `compute_class_weight` 计算类别权重，并应用于交叉熵损失函数（CrossEntropyLoss），强制模型关注少数类。
- **网络设计**：包含两层 Conv1d（提取波形特征） + BatchNorm（加速收敛） + MaxPool1d（降维） + Dropout（防过拟合） + 自适应池化（AdaptiveAvgPool1d）。

**实验结果与医学分析：**
- **总体表现**：模型整体准确率达到 **65%**，Loss 曲线从 1.7 稳定下降至 1.1，收敛良好。
- **深睡识别（N3）**：表现极佳，Recall（召回率）高达 **90%**。证明深度睡眠期巨大的 Delta 慢波特征极其明显，CNN 极易捕捉。
- **边界混淆（N1 与 W）**：N1（浅睡）有较大概率被错判为 W（清醒）。医学解释：N1 是清醒到睡眠的过渡期，两者在单通道脑电上的高频特征极度相似。
- **REM 期失效**：模型几乎无法识别 REM（做梦）期。工程反思：单通道脑电数据（仅有 Fpz-Cz）不足以支撑 REM 判读，必须引入眼电（EOG）和肌电（EMG）辅助。这为后续的“多通道数据融合”埋下伏笔。
